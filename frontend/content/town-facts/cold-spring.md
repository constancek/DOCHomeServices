# Cold Spring, KY: verified facts (service-neutral)

**Errors in locations.ts (slug 'cold-spring'):**
- "Older houses see corrosion leaks" overstates the older stock. Median year built is 1999; 47.5% of units were built 2000 or later and only 9.9% predate 1960 (section 2). https://censusreporter.org/profiles/16000US2116372/
- "Growing city along US-27" is right: US 27 (Alexandria Pike) runs through it, and population went from 3,806 (2000) to 6,216 (2020). https://en.wikipedia.org/wiki/Cold_Spring,_Kentucky
- Not wrong but missing: 23.8% of units are single-family attached (townhouse/condo style), section 2.
- "Any day of the week" / "every day" are company claims; check against stats.md.

## 1. Where it is
- Home rule-class city in Campbell County, KY. 2020 population 6,216; about 4.75 sq mi. ZIP 41076. Neighbors: Wilder (NW), Highland Heights (N), Crestview (NE), Alexandria (SE). The Licking River forms the southwest boundary, with Taylor Mill (Kenton County) across it. https://en.wikipedia.org/wiki/Cold_Spring,_Kentucky
- A "Cold Spring, KY 41076" mailing address can fall in Wilder (4 Plum St geocodes to Wilder city). Check the place, not the mailing city. https://geocoding.geo.census.gov/geocoder/

## 3. Permits
- Cold Spring's code (Chapter 150) designates the **Campbell County Fiscal Court Department of Building Inspections** as the local enforcement agency for the Kentucky Building Code and Residential Code (search summary; the code page returned 403). https://codelibrary.amlegal.com/codes/coldspring/latest/coldspring_ky/0-0-0-10429
- **HVAC permit office: unverified.** Cold Spring is not named on the state inspector list for Campbell County (the county's local HVAC list covers Alexandria, Bellevue, California, unincorporated county, Crestview, Dayton, Fort Thomas, Highland Heights, Melbourne, Silver Grove, Southgate, Wilder and Woodlawn). It may fall to the state HVAC inspector; not confirmed. https://dhbc.ky.gov/Documents/Campbell%20County.pdf (updated 10/20/2026)
- Plumbing inspections: state plumbing inspector. Same list.
- Kentucky requires a permit to replace a furnace, condensing unit or heat pump. https://apps.legislature.ky.gov/law/kar/titles/815/008/070/
- Fees and timings: don't use.
